Samples and test results

How samples, blow counts and laboratory results are entered and drawn.

Sample depth interval

Each sample has a top and bottom depth: the interval the sampler was driven or pushed over. The sampler symbol is drawn over that interval, and the sample's values are written level with the middle of it.

  • For an SPT, use the full 18 in (0.45 m) drive, e.g. 10.0 to 11.5 ft.
  • For a Shelby tube or core run, use the length pushed or cored, and give the recovered length in recovery.
  • For a refusal, use the depth actually reached, e.g. 13.0 to 13.3 m for 50 blows in 5 in.

Sampler types

Set a sample's type to one of these codes (spelled exactly as shown) to choose its symbol. Without a type, the sample is drawn as Other.

You can replace any of these symbols with your own, or add new sampler types; see Your own hatches.

Blow counts

There are two fields, and you can give either or both:

  • blow_count is the value you want shown in the blow count column: a number such as 14 (an SPT N-value, or blows per foot for another sampler), or text for refusal, such as "50/5in" or "50/150mm".
  • blows is the list of blows per increment, such as [6, 8, 10] for an SPT's three 6 in increments.

If you give blow_count, that's what is shown. If you give only blows, the increments are shown joined with dashes: 6-8-10.

Blow counts are shown as given

The viewer doesn't correct blow counts for energy, overburden or sampler type. A Modified California blow count is shown as recorded, not converted to an SPT N-value. Put corrected values in remarks if you need them on the log.

Energy ratio. Give the hammer's energy ratio in metadata.energy_ratio; it's shown in the header as "ER = 82%". If it varies between samples, give energy_ratio on each sample and add the energy_ratio column (it isn't in the default column list; see Display options).

Laboratory results

Results from a test on a sub-sample go on the sample they came from. If you have results that don't belong to a sample (for example, from a separate lab sample at a different depth), add a sample for them with "type": "Other", or leave type out.

Dry density isn't a field; convert it to dry unit weight first (multiply Mg/m³ by 9.81 to get kN/m³). The AGS4 and DIGGS imports do this for you.

Sample description and remarks

description and remarks each get their own column, which wraps long text. Use description for what the sample is ("Undisturbed, sent for CU triaxial") and remarks for notes such as "Refusal on cobble", "RQD 45%" or "Poor recovery".
