Columns and layout

Choose which columns a log has, in what order, how wide and with what headings, and add columns of your own, such as pocket penetrometer readings or undrained strength.

The layout is saved in the log's JSON, in a layout section, so it travels with the data: the log looks the same on the web page, through the API and on another computer. A log without a layout uses the built-in one.

With the Layout… window

On the viewer page, click Layout… above the text box. The window lists every column, in order. Every change shows in the preview straight away.

  • Show: tick or untick a column. Depth, graphic log and material description are always drawn. A column marked "No data in this log" isn't drawn until it has some.
  • Heading: type a new heading, e.g. "Soil description" or "w (%)".
  • Width: a relative width. The columns share the log's width in proportion to these numbers, so a column with width 6 is twice as wide as one with 3. The bar above the table shows the shares.
  • Order: the ↑ and ↓ buttons move a column left or right in the log.
  • Log width and Font size at the top set the size of the whole drawing.

When you're done, click Done. Undo changes goes back to how the log was when the window opened, and Use built-in layout removes this log's layout altogether.

Adding your own columns

Under Add a column, choose a type and a heading, and click Add column:

TypeForExamples
Value for each sampleA field measurement on the sample, level with the sampler symbolPocket penetrometer, torvane, PID reading, corrected N60
Value for each specimenA laboratory result, on the specimen rows beside the water content and limitsUndrained shear strength, organic content, % clay
Blank columnAn empty column to write in by hand on a printed logField notes, checked by

Then click Values… beside the new column to type its value for each sample or specimen. The column appears in the log once it has a value (a blank column is always drawn). Numbers are shown as you type them. Remove deletes the column and its values.

Writing the layout by hand

The window writes a layout section like this, and puts the values of custom columns in each sample's or specimen's custom:

"layout": {
  "width": 1000,
  "font_size": 10,
  "columns": [
    "depth",
    { "id": "graphic", "width": 5 },
    { "id": "description", "width": 25, "label": "Soil description" },
    "sample_type", "sample_name", "blow_count",
    { "id": "pp", "source": "sample", "field": "pocket_pen", "label": "PP (tsf)", "width": 3 },
    "specimen", "specimen_name", "water_content",
    { "id": "cu", "source": "specimen", "label": "cu (kPa)", "decimals": 0 },
    { "id": "remarks", "width": 12 },
    { "id": "notes", "source": "blank", "label": "Field notes", "width": 10 }
  ]
},
"samples": [
  { "top": 5, "bottom": 6.5, "name": "S-2", "type": "SPT", "blow_count": 9,
    "custom": { "pocket_pen": 1.5 },
    "specimens": [ { "top": 5.5, "bottom": 6, "water_content": 31, "custom": { "cu": 42 } } ] }
]

Each entry of columns is either a column id, or an object:

FieldMeaning
idRequired. A built-in column id (below), or a new id for your own column
widthRelative width. A built-in column without one gets its usual share (about 4 for the depth and graphic log, 3 for a value column, 30 for the description, 15 for remarks).
labelThe heading. Defaults to the built-in heading, or the id.
sourceFor your own column: "sample" (from each sample's custom), "specimen" (from each specimen's custom) or "blank" (empty)
fieldThe key in custom. Defaults to the id.
decimalsRound numbers to this many decimals. Without it, numbers are shown as given.

Rules: depth, graphic log and description are always drawn, even if left out; columns with no data are hidden as usual (blank columns aren't); and an unknown id without a source, an id listed twice, or your own column using a built-in id is an error.

Built-in column ids

In the default order:

depth, elevation, groundwater, graphic, uscs, description,
sample_type, sample_name, sampler_diameter, blow_count,
specimen, specimen_name,
water_content, total_unit_weight, dry_unit_weight, specific_gravity, fines_content, liquid_limit, plastic_limit,
remarks

One more, energy_ratio (the hammer energy ratio of each sample), is only drawn when you add it.

Layout and display options

Display options given when the log is drawn, such as the API's width, font_size or columns parameters, or the web page's settings, take precedence over the log's layout. One exception: on the web page, a log's own width is kept. The columns option can list a layout's custom columns by their ids. See Display options.
