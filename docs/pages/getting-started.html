Your first boring log

In this tutorial you'll draw a log for a 20 ft boring, starting with three layers and then adding samples, blow counts, lab results, groundwater and a header.

Step 0: Open the viewer

Go to uclageo.com/boring-log-viewer. The page has two halves:

  • Left: a text box where the boring log data goes.
  • Right: the drawn log, which updates as you type, with buttons to download it.

Click Clear to empty the text box. (To see a finished example first, choose one from Load example….)

Your data stays on your computer

The web page draws the log inside your browser. The data you type is not sent anywhere, and it is kept in your browser so it's still there if you reload the page.

Here's what each part means:

  • "schema_version": "1.0" is always the same. It tells the viewer which version of the format you are using.
  • "units": { "length": "ft" } says the depths are in feet. Leave units out to use metres.
  • "metadata": { "boring_name": "B-1" } gives the log its title.
  • "layers" is the list of strata, from the top down. Each layer has a top and bottom depth (measured down from the ground surface) and a description.

Notice what it worked out on its own:

  • The graphic log symbols come from the descriptions. "poorly graded SAND with silt" is drawn as SP-SM and "lean CLAY" as CL, using the ASTM D2487 group names.
  • The first layer is drawn as fill, because its description ends with "(fill)".
  • The USCS column shows the symbols it inferred, in parentheses, so a reader can tell they weren't recorded by the logger. The legend explains the parentheses.

If you'd rather choose the symbols yourself, add "uscs": "SM" to a layer. A symbol you give is always used, and shown without parentheses. See Graphic log and soil symbols for how the symbols are chosen.

A few JSON rules

JSON is strict about punctuation. If the log disappears and an error appears under the text box, it's usually one of these:

  • Names and text go in double quotes: "description": "Gray, soft, wet, lean CLAY". Numbers don't: "top": 4.
  • Items in a list, and fields in an object, are separated by commas, but there is no comma after the last one.
  • Every { needs a matching }, and every [ a matching ].
  • Decimal numbers use a point: 12.5, not 12,5.

Click an error message to jump to the problem in the text box. The Format button re-indents the text neatly once it's valid.

Step 2: Samples, test results, groundwater and the header

Now replace the text with the complete boring:

What's new:

  • units now also sets unit weights in pcf and diameters in inches.
  • metadata fills the header: project, ground elevation (which adds an elevation scale), date, drilling method, borehole diameter, hammer and who logged it.
  • groundwater is a list of water level readings, drawn as ▽ in the water level column.
  • uscs on each layer gives the recorded symbol.
  • samples is the list of samples. Each has a top and bottom depth, a name, a sampler type (which picks the symbol), and any test results: blow counts, water_content (%), fines_content (%), dry_unit_weight, liquid_limit and plastic_limit.

Each sample's values are lined up with its sampler symbol, and the depth scale stretches if needed to keep them from overlapping. Every field is described in the data format reference; the sampler symbols are listed in Samples and test results.

Leave out what you don't have

Every field except top and bottom is optional. A column with no data in the whole log isn't drawn. You can also write null for a missing value ("water_content": null), which is handy when exporting from a spreadsheet or database.

Step 3: Download or print

Above the drawing are the controls:

  • Units converts the whole log to metric or US units for display, whatever units the data is in.
  • Width sets the width of the drawing in pixels. Wider gives more room for descriptions.
  • Header, Legend, References, Fit text and Hide empty columns turn parts of the drawing on and off. See Display options.
  • SVG downloads a vector image: sharp at any size, editable in Inkscape or Illustrator, and best for reports.
  • PNG downloads a picture at 1×, 2× or 3× resolution, for slides or documents that don't take SVG.
  • Print / PDF opens the print dialog with only the log on the page. Choose "Save as PDF" as the printer to get a PDF.
