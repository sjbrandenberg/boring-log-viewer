Several logs and the map

The web page can hold all the borings of a site at once: each in its own tab, all of them on a map, and all downloadable in one ZIP file.

Tabs

Each open log has a tab above the text box. Click a tab to edit and preview that log; ‹ and › step through them, and the × on a tab closes it.

A new tab opens for:

  • each JSON file you open or drag onto the text box. You can open several files at once;
  • each borehole in an AGS4 or DIGGS file (those with strata). A file with twelve boreholes opens as twelve tabs (see Importing AGS4 and DIGGS);
  • an example from Load example…. One example opens all four borings from a site in Nantou, Taiwan, at once;
  • + New, which starts an empty log.

The open logs, and your option settings, are kept in your browser between visits, so they're there when you come back. They stay on your computer.

Downloading every log

With more than one log open, All logs (ZIP) downloads every open log as both SVG and PNG in one ZIP file, named after each boring. SVG, PNG and Print / PDF still work on the log you're looking at.

The map

Below the text box, Location opens a map of every open log that has a latitude and longitude in its metadata.

  • Click a marker to open that log.
  • The map zooms to the logs within 50 km of the one you're editing, so borings from another site don't shrink the view.
  • The button at the top right switches between a Street map (OpenStreetMap) and Satellite imagery (Esri).
"metadata": { "boring_name": "NAS-3", "latitude": 23.908442, "longitude": 120.687592 }

Coordinates are decimal degrees, with west longitudes and south latitudes negative.

Privacy

The map pictures (tiles) are the only thing the page loads from elsewhere: from OpenStreetMap or Esri, for the area you're looking at. Your log data isn't sent with them.

Cross-sections and a 3D model

To see the borings of a site connected in cross-sections and a 3D model, send them together to the site API, which returns a page with all three views. See Site view: cross-sections and 3D.
