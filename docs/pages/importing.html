Importing AGS4 and DIGGS

Open a standard geotechnical data file and the borings in it are drawn, with no conversion on your part.

How to open a file

  1. On the viewer page, click Open file…, or drag the file onto the text box.
  2. Each borehole with strata opens as its own log, in its own tab (see Several logs and the map).
  3. The file is converted to the viewer's JSON, which appears in the text box, and the log is drawn. A note above the text box reports anything that couldn't be read.

The conversion runs in your browser; the file isn't uploaded. You can edit the converted JSON like any other log, for example to fix a description or add a reference, and save it for later.

From a script, send the file to the render API instead. To draw every borehole of the file together in cross-sections and a 3D model, send it to the site view.

AGS4

AGS4 is the data transfer format of the Association of Geotechnical and Geoenvironmental Specialists, used in the UK and many other countries. Each borehole (LOCA_ID) becomes one log. AGS depths are in metres, so the logs are in SI units (use the Units option to display them in feet).

AGS4 groupBecomes
PROJ, LOCA, HDIAHeader: project, site, ground level, dates, hole type (spelled out with the ABBR group, e.g. CP = Cable percussion), driller, latitude and longitude when given, remarks, hole diameter
GEOLLayers (GEOL_DESC). Rows without a base depth are left out, with a warning.
DETLDepth notes
SAMPSamples. B/LB = Bulk, BLK = Block, D = Disturbed, U/UT/TW = Shelby, P = Piston, SPT, C = Core, WS = Direct push. Other types (ES, W...) are drawn as Other, with the type in the sample number ("3 ES"). A sample with only a top depth is drawn 0.15 m long (0.45 m for an SPT). SAMP_DESC and SAMP_REM together become its remarks.
ISPTSPT N-values (ISPT_NVAL, or the main drive of a refusal such as "50/150mm"), blows per 150 mm increment (from the six 75 mm increments), energy ratio
LNMC, LLPL, GRAG, LDEN, LPDNWater content, liquid and plastic limits (NP = non-plastic), fines content, dry unit weight (from dry density), specific gravity. Each is matched to its sample, and put on a specimen: one per SPEC_REF and SPEC_DPTH.
WSTG (and AGS3-style WSTK)Groundwater: water strikes

"MADE GROUND", the British term for fill, is drawn with the fill symbol. AGS3 files aren't supported and are rejected with a message. The import was tested on 48 boreholes from the British Geological Survey's National Geoscience Data Centre.

DIGGS

DIGGS (Data Interchange for Geotechnical and Geoenvironmental Specialists, diggsml.org) is an XML format used by several US state DOTs. Versions 2.5, 2.6 and 3.x are read. Each Borehole (also TestPit and Trench) becomes one log; CPT soundings are skipped.

DIGGSBecomes
Project, BoreholeHeader: project, boring name, latitude, longitude and elevation, dates, drilling method and rig, logger and drilling contractor, remarks
Linear referencingThe log's length unit (ft or m), per borehole
LithologyObservationLayers, from the description, or one built from consistency, color, constituents and moisture. USCS from the classification code. An observation at a single depth inside a layer becomes a depth note.
SamplingActivitySamples: SPT, Shelby, core sizes, bulk and so on, with recovery
Test resultsSPT N-value and blows per increment; water content, liquid and plastic limits, non-plastic, fines, dry density (as unit weight), specific gravity, USCS. Matched to samples by reference, or else by depth, and put on the specimen they name (or one specimen per tested interval).
WaterStrikeGroundwater

Tested on the official DIGGS examples, including the Ohio DOT projects (13 borings).

If something is missing

Different programs fill these formats in different ways. If a value you expect isn't on the log, check the converted JSON in the text box: if it's there, see the data format reference for where it's drawn; if it isn't, the file may store it in a group or property the import doesn't read. Please open an issue with an example file (with any confidential data removed) and we'll look at adding it.
