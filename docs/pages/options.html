Display options

Options change how a log is drawn without changing its data. Most are buttons and checkboxes on the web page; all of them can be given to the API or the JavaScript module.

Units

The data can be in one system and the drawing in another. A boring entered in feet can be drawn in metres by choosing Metric on the web page, or units=m in the API. Every depth, elevation, recovery, unit weight and diameter is converted; percentages and blow counts aren't affected.

Size and depth scale

  • For a page in a report, a width of 800 to 1000 px works well. Give more width when descriptions are long or there are many lab columns.
  • To draw several borings at the same depth scale (e.g. for a fence diagram or a side-by-side comparison), turn off fit_text and give the same scale to each, e.g. scale=40 for 40 px per foot.
  • With fit_text off and no scale, the log body is height px tall whatever the boring depth.

Choosing columns

The default columns, in order:

depth, elevation, groundwater, graphic, uscs, description,
sample_type, sample_name, sampler_diameter, recovery, blow_count, sample_description,
water_content, dry_unit_weight, specific_gravity, fines_content, liquid_limit, plastic_limit,
remarks

There is one more column, energy_ratio, for a per-sample hammer energy ratio. It isn't in the default list, so add it where you want it. For example, a log with only the field data:

columns=depth,graphic,uscs,description,sample_type,sample_name,blow_count,energy_ratio

With hide_empty_columns on (the default), listed columns that have no data are still left out.

Symbol inference

infer_uscs and infer_materials control the two kinds of guessing described in how the symbol is chosen. Turn them off when your data already gives a uscs or hatch for every layer and you don't want the descriptions second-guessed.
